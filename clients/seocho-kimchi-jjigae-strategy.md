# 서초김치찌개 — 마케팅 전략

`clients/seocho-kimchi-jjigae.json` 기준. 퍼널 모델은 `docs/client-revenue-funnel.md`(노출×클릭률×전환율×재방문율) 그대로 따른다. 각 액션에는 Growth Portfolio 태그(🟩안전/🟦핵심/🟧실험 — `docs/ai-growth-os-future-vision.md`의 정직한 최소 버전, 데이터 계산 아니라 편집적 분류)를 붙였다.

**AI Freedom Level: 3 — 승인 후 실행** (`company_core.py`로 실제 계산됨, restaurant 업종 기본값). 콘텐츠 초안까지는 자동으로 만들 수 있고, 최종 발행은 항상 사람 승인이 필요하다는 뜻. 광고비·가격 변경 같은 건 이 레벨에서도 항상 사람 몫이다.

**정량 분석(목표매출 역산·What-If·이익환산) 아직 대기 중**: 목표매출·객단가·방문전환율·변동비율을 아직 안 주셔서 `revenue_engine.py`의 Goal Decomposer/What-If/Digital CFO는 못 돌렸다. 아래 전략은 전부 정성적(퍼널 구조 기반) 판단이고, 숫자로 "이걸 하면 얼마나 버는지"는 저 값들이 있어야 나온다.

## 1. 이 업체가 가진 실제 자산 (지어낸 것 없음 — known_facts + public_references 기준)

- 다이닝코드 평점 4.5, 8년째 운영 — 신뢰도 스토리텔링 재료
- **투톱 메뉴**: 김치찌개(대표) + 냉삼(냉동삼겹살, 사장님 확인) — 단일메뉴 맛집 이미지에 갇히지 않고 저녁 회식 수요까지 잡을 수 있는 조합
- 충주사과김치 + 할머니 손맛 재현 — "레시피 스토리" 콘텐츠 소재
- 연예인 사인 다수 보유 — 사회적 증명(social proof) 자산
- **실제 미디어 노출 이력**: 유튜브 영상, SBS 생방송투데이 '서울 김치찌개 TOP5' 방송 출연 — 이미 만들어진 인지도 자산인데 활용을 안 하고 있었을 가능성 높음
- 예술의전당 도보권 — 공연 관람객이라는 뚜렷한 2차 타겟 고객군 존재

## 2. 퍼널 단계별 전략

### ⚠️ 0순위 — 네이버 플레이스 미등록으로 확인됨 (2026-08-26)
사장님이 네이버 지도 앱에서 "서초김치찌개"로 직접 검색 → **정확히 일치하는 결과가 없음** (근처 다른 김치찌개집들만 대체 노출됨). 이건 지금까지의 모든 콘텐츠 전략보다 우선순위가 높다 — 한국 로컬 외식업 검색 유입의 대부분이 네이버 지도/플레이스에서 오는데, 거기에 아예 없으면 블로그·SNS로 아무리 노출을 만들어도 "찾아오는 길"이 없는 것과 같다.
- **즉시 액션**: 네이버 스마트플레이스(smartplace.naver.com)에 사업자 등록 — 사업자등록증 인증이 필요해 사장님이 직접 해야 함(대행 불가)
- 등록 완료되면 이 세션에서 `local_place_agent.py`로 만들어둔 체크리스트·소개문구를 그대로 입력하면 됨
- 확인 필요: 혹시 다른 상호명(예: 예전 상호, 오타)으로 등록돼 있을 가능성도 있으니, 정말 미등록인지 상호명 몇 가지로 다시 검색해보는 것도 병행

### 노출 (Impressions)
- 🟩안전 **네이버 플레이스**: `place_plan.md`의 체크리스트(대표사진 10장+, NAP 일치, 월 1회 소식) 우선 적용 — 단, 위 0순위(등록 자체)가 먼저
- 🟦핵심 **블로그 롱테일 키워드**: "서초 냉삼 맛집", "예술의전당 공연 전 식사", "서초동 김치찌개+냉삼 투톱" — 김치찌개 단일 키워드 경쟁을 피해 아직 비어있는 조합 키워드 선점
- 🟩안전 **기존 미디어 자산 재활용**: SBS 방송 출연·유튜브 영상 링크를 플레이스 소개란·블로그 글에 임베드 — 이미 확보된 신뢰 자산을 노출 채널에 다시 태우는 것, 콘텐츠 원가 0
- 🟧실험 **숏폼**: 냉삼 굽는 장면 + 연예인 사인 벽을 훑는 릴스/쇼츠 — 새 포맷, 저비용이지만 결과 검증 안 됨

### 클릭률 (CTR)
- 🟦핵심 대표 이미지/썸네일을 "연예인 사인 벽" 또는 "냉삼+김치찌개 한 상" 비주얼로 교체
- 🟦핵심 제목에 사회적 증명 수치 명시: "8년째 4.5점", "SBS 방송 출연" (사실 그대로만, 과장 문구 금지 — `docs/adsense-readiness-product.md`와 같은 원칙: 검증된 것만 표기)

### 전환율 (Conversion)
- 🟦핵심 플레이스 소개문에 명확한 CTA + 웨이팅 정보 명시(브레이크타임 15~17시 고지로 헛걸음 방지 = 부정경험 예방)
- 🟧실험 예술의전당 공연 관람객 타겟: "공연 전 든든하게, 공연 후 든든하게" 같은 시간대별 메시지 — 새로운 고객 세그먼트 타겟이라 반응 검증 안 됨
- 🟦핵심 냉삼 세트/2인 세트 등 명확한 조합 메뉴 CTA (있는 메뉴만 — 없는 세트를 지어내지 않음, 실제 메뉴 확인 필요)

### 재방문율 (Retention) — 이 업체의 실제 강점
- **사장님 확인: "한 번 먹어본 손님은 계속 재방문하는 단골 비중이 높다"** — 이건 마케팅 문구가 아니라 이미 벌어지고 있는 실제 현상이라, 퍼널상 가장 손 안 대도 되는 단계였을 가능성이 높음. 대신 이 강점을 **노출·전환 단계로 끌어와서 신규 고객에게 신뢰 신호로 보여주는 게 핵심 과제**
  - 🟧실험 콘텐츠 소재: "N년째 오시는 단골님" 인터뷰/후기(실제 단골 손님 동의 받아서), "재방문율이 높은 이유" 스토리텔링 — 섭외·동의 절차가 껴서 실행 난이도 있음
  - 🟩안전 플레이스 리뷰 중 재방문 언급하는 후기를 대표 후기로 고정 노출
  - 🟧실험 단골 대상 혜택(도장 적립 등 실제 있는 제도만) 있으면 노출, 없으면 새로 만드는 걸 검토
- 🟩안전 `review_target_phone`이 아직 비어있음 — 채워지면 카카오 알림톡 리뷰 요청·재방문 유도 자동화 가동 가능(`orchestrator.send_review_reminder`)
- 🟦핵심 냉삼 시즌 메뉴/이벤트 안내로 재방문 트리거

## 3. 지금 당장 실행 가능한 것 vs 막혀있는 것

| 항목 | 상태 |
|---|---|
| 로컬 플레이스 체크리스트, 소개문구, 리뷰 요청/대응 문구 | ✅ 자동 생성됨 (`local_place_agent.py`, 이번에 실행 완료) |
| 블로그 제목·목차·CTA 뼈대 | ✅ 자동 생성됨 |
| 블로그 실제 본문(SEO 롱폼 글) | ⛔ `ANTHROPIC_API_KEY` 미설정 — 지금은 뼈대만 나옴, 키 넣으면 바로 본문까지 자동 생성 |
| 카카오 알림톡 리뷰 리마인드 | ⛔ `review_target_phone` 비어있음 — 채우면 바로 가동 |
| SBS/유튜브 노출 이력을 콘텐츠에 반영 | ⛔ 사람이 직접 확인 필요 (원문 링크가 실제로 이 업체 맞는지 최종 확인 — public_references에 "재확인 필요"로 남겨둔 부분) |

## 4. 우선순위 제안 (순서대로)

0. **네이버 스마트플레이스 등록** (사장님 직접, 사업자 인증 필요) — 이게 안 되면 나머지는 다 의미가 반감됨
1. 냉삼 메뉴 실제 정보(가격, 2인 이상 여부 등) 확인해서 알려주기 — 그래야 세트 CTA·블로그 콘텐츠에 구체적으로 쓸 수 있음
2. `review_target_phone` 채우기 — 리뷰·재방문 자동화 즉시 가동
3. ANTHROPIC_API_KEY 연결 — 블로그 본문 자동 생성 가동
4. SBS/유튜브 영상이 진짜 이 업체 맞는지 최종 확인 — 맞으면 콘텐츠에 적극 활용(신뢰도 최고 자산)

## 5. Growth Portfolio 요약 — 뭐부터 손대야 하나

🟩안전(4개) → 🟦핵심(6개) → 🟧실험(4개) 순으로 처리하는 걸 권장한다. 안전 항목은 이미 검증된 자산(플레이스, 기존 리뷰, SBS/유튜브, 카카오 채널)을 그대로 재활용하는 거라 실패해도 잃을 게 없고, 지금 바로 시작해도 된다. 실험 항목(숏폼, 공연 타겟 메시지, 단골 인터뷰, 신규 혜택)은 콘텐츠 제작 부담이나 섭외가 껴서 안전·핵심 먼저 자리잡은 뒤에 시도하는 게 순서상 맞다.

## 6. 정량화하려면 필요한 것 (다시 정리)

- **목표매출**: 있어야 `revenue_engine.decompose_goal()`로 "몇 명 더 와야 하는지" 역산 가능
- **객단가·방문전환율**: 있어야 위 역산 + `what_if()`로 "뭘 올리는 게 제일 효율적인 지렛대인지" 계산 가능
- **변동비율**: 있으면 "매출을 늘리면 실제로 얼마가 남는지"(기여이익)까지 계산 가능

이 3개(또는 목표매출만이라도) 주시면 바로 실제 숫자로 업데이트하겠습니다.
