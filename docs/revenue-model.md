# 매출 성장 매커니즘

`docs/marketing-agent-plan.md`의 로드맵을 "매출이 실제로 어떻게 늘어나는가"의 관점에서 다시 설명한다. 아래 단가·매출 숫자는 실제 시장 데이터 없이 잡은 **가정치**이며, Phase 0 파일럿 결과가 나오는 대로 보정해야 한다.

## 1. 핵심 공식

```
월매출(MRR) = 고객사 수 × 고객당 평균 단가
성장분     = (신규계약 - 이탈) × 단가  +  기존 고객 업셀
```

매출은 "고객 수를 늘리는 것"과 "고객 1곳당 단가를 올리는 것" 두 축으로 늘어난다. 이 모델의 핵심은 후자를 가능하게 만드는 것 — 즉 성과가 눈에 보여야 업셀·재계약·소개가 일어난다.

## 2. 가격 구조 (단가 앵커, 가정치)

| 상품 | 월 단가 | 비고 |
|---|---|---|
| 플레이스 단독 | 30~50만원 | 진입 상품, 착수 빠르고 성과가 2주 내 보임 → 계약 전환율이 가장 높음 |
| 블로그 단독(월 4건) | 50~80만원 | |
| 블로그+플레이스 패키지 | 90~130만원 | 크로스셀용, 개별 합보다 살짝 저렴하게 묶어 전환 유도 |
| 풀패키지(블로그+플레이스+웹 유지보수) | 150~300만원 | 업셀의 종착점 |
| 웹/랜딩페이지 제작(1회성) | 200~500만원 | 별도 프로젝트 단가, 이후 월 유지보수로 전환 |
| 메타 광고 운영 수수료 | 광고비의 15% 또는 정액 20~30만원 | 광고비 자체는 고객 예산(우리 매출 아님), 이 라인은 콘텐츠 라인과 별개의 업셀 — 전환이 검증된 고객에게만 제안 |

## 3. 매출이 늘어나는 3개의 루프

### 루프 1 — 신규 획득 (Acquisition)
`파일럿 사례 → 전후 성과 비교자료 → 아웃리치/지인소개 → 계약`
이 루프의 속도는 "눈에 보이는 성과"에 달려 있고, 그 성과는 8개 에이전트의 산출물 품질 + 성과 분석 에이전트의 리포트가 만든다.

### 루프 2 — 업셀 (Expansion)
`플레이스 단독으로 시작 → 3~4주 성과 리포트로 신뢰 형성 → 블로그/웹 라인 추가 제안 → 단가 상승`
신규 계약보다 훨씬 저비용이다 — 이미 신뢰가 확보된 고객에게 파는 것이기 때문. 시간이 지날수록 고객 1곳당 평균 단가가 자연히 오르는 구조를 만든다.

### 루프 3 — 리텐션 → 레퍼럴 (Retention & Referral)
`매주 자동 성과 리포트 → 이탈 방지 → 만족한 고객이 동종업계/지인에게 소개 → 광고비 없는 신규 유입`
이 루프가 궤도에 오르면 영업 활동을 줄여도 매출이 느는 구간(Phase 3의 "인바운드 전환")이 생긴다.

세 루프가 겹쳐 돌면서 **고객 수 증가 + 고객당 단가 증가 + 획득 비용 감소**가 동시에 일어나는 것이 이 모델의 매출 매커니즘이다.

## 4. Phase별 매출 · 작업 매핑 (가정치)

| Phase | 기간 | 고객 수 | 평균 단가 | 월매출(대략) | 핵심 루프 | 이 기간 실행 작업 |
|---|---|---|---|---|---|---|
| 0 | 1~4주 | 3 (무료/저가) | 0~10만원 | ~0~30만원 | — (사례 확보가 목적, 매출 아님) | 브리프 수집 → 8개 에이전트 가동 → 4주간 산출물 생산 → 전후 성과 비교자료 작성 |
| 1 | 5~10주 | 5 (유료) | 50~80만원 | 250~400만원 | 루프 1 | 파일럿 자료로 아웃리치 → 온보딩 → 주간 생산 사이클 반복 → 주간 리포트 발송 |
| 2 | 11~20주 | 20 | 80~120만원 (업셀 반영) | 1,600~2,400만원 | 루프 1 + 2 | 신규계약 지속 + 기존 고객 업셀 제안 + 이탈 관리 — 이 시점에 대시보드/채용 검토 트리거 도달 |
| 3 | 21주~ | 40+ | 100~150만원 | 4,000만원+ | 루프 3 | 인바운드 문의 응대 중심, 업종(뷰티/F&B 등)·지역 확장, 필요 시 채용 |

## 5. 마진이 고객 수를 따라 개선되는 이유

- AI 에이전트 운영비(LLM API 호출 등)는 고객 1곳당 한계비용이 매우 낮다
- 반면 매출은 고객 수 × 단가로 늘고, 업셀까지 더해지면 선형 이상으로 늘어난다
- 결과적으로 **고객 수가 늘수록 마진율이 개선**된다 — 사람을 늘리지 않고 AI 에이전트로 확장하는 것의 경제적 근거이며, Phase 0에서 무료/저가로 파일럿을 도는 이유도 여기에 있다(사례가 루프 1의 연료이기 때문에 초기 손해를 감수한다).
