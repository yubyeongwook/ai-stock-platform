# 에이전트별 상세 스펙 & 업무 프로세스

`docs/marketing-agent-plan.md`의 9개 에이전트를 실제로 돌리기 위한 상세 스펙이다. 각 에이전트마다 (1) 미션, (2) 필요 구성(인풋·도구·아웃풋 포맷), (3) 단계별 업무 프로세스를 정의한다.

## 0. 전체 파이프라인 (오케스트레이터 기준 하루 흐름)

```
[오케스트레이터] 캘린더 기준 라인별 태스크 배정
        │
        ▼
[라인 에이전트 1~8] 각자 초안 생성
        │
        ▼
[오케스트레이터] 1차 스크리닝 (포맷·키워드·금지어 자동 체크)
        │
   통과 │ 반려 → 담당 에이전트 재작업
        ▼
[나] 최종 검수 (브랜드톤·규제·팩트체크)
        │
        ▼
[발행/게시] → [성과 분석 에이전트] 지표 회수 → 다음 사이클 인풋으로 피드백
```

이 루프가 클라이언트당 매일(리뷰·플레이스)~매주(블로그·웹) 단위로 반복된다.

---

## 1. 블로그 콘텐츠 에이전트

**미션**: 키워드 기반 SEO 블로그 포스트 초안 생성

**필요 구성**
- 인풋: 고객 브리프(업종, 타겟 키워드 리스트, 브랜드 톤 가이드, FAQ 소재), 경쟁사 상위노출 블로그 샘플(선택)
- 도구: 키워드 리서치 데이터(검색량·연관검색어), 업종별 톤앤매너 프롬프트 템플릿, 업종별 금지어/규제 문구 리스트(예: 의료광고법상 과장·치료효과 단정 표현)
- 아웃풋 포맷: 제목 후보 3개, 목차(H2/H3), 본문 초안(마크다운), CTA, 타겟 키워드 태그

**업무 프로세스**
1. 이번 주 발행 키워드 큐에서 1건 pull (오케스트레이터가 배정)
2. 키워드 의도 분석 (정보성/거래성 구분)
3. 제목 후보 3개 생성
4. 목차(H2/H3) 설계
5. 본문 초안 생성 — 업종 금지어 필터 자동 적용
6. 내부링크·CTA 삽입
7. "QA 대기" 상태로 오케스트레이터 큐에 제출

## 2. 블로그 최적화 에이전트

**미션**: 이미 발행된 블로그의 제목·썸네일·내부링크·발행 주기 최적화

**필요 구성**
- 인풋: 발행된 블로그 URL 목록, 노출 순위·트래픽 데이터(서치어드바이저/GA), 콘텐츠 캘린더
- 도구: 순위 추적 데이터, 썸네일 디자인 가이드, A/B 타이틀 테스트 로직
- 아웃풋: 최적화 제안 리포트(제목 변경안, 내부링크 삽입 위치, 재발행 우선순위)

**업무 프로세스**
1. 주간 발행 콘텐츠 성과 데이터 pull
2. 순위 하락·정체 포스트 식별
3. 제목·썸네일 개선안 3개 생성
4. 내부링크 기회(신규 ↔ 기존 포스트) 매핑
5. 리프레시 우선순위 리스트 제출 → 승인 후 콘텐츠 에이전트에 재작업 요청

## 3. 로컬 SEO 에이전트

**미션**: 네이버 플레이스·지도 노출 최적화

**필요 구성**
- 인풋: 업체 기본정보(상호·주소·전화=NAP), 카테고리, 영업시간, 사진 소재
- 도구: 플레이스 최적화 체크리스트 템플릿, 경쟁업체 플레이스 벤치마킹 데이터
- 아웃풋: 최적화 체크리스트(완료 여부), 소개문구 초안, 월간 소식 콘텐츠 초안

**업무 프로세스**
1. 등록정보 감사(현재 플레이스 페이지 데이터 수집)
2. NAP 일치 여부 검증(모든 채널 동일한지)
3. 소개문구·카테고리 키워드 최적화안 작성
4. 월간 소식(이벤트·공지) 콘텐츠 초안 생성
5. 체크리스트 갱신 후 오케스트레이터 제출

## 4. 리뷰·평판관리 에이전트

**미션**: 리뷰 유도 및 대응 문구 생성

**필요 구성**
- 인풋: 최근 리뷰 데이터(긍정/부정), 고객 응대 톤 가이드
- 도구: 감정 분류 로직, 리뷰 요청 발송 채널(문자/카카오 템플릿)
- 아웃풋: 리뷰 요청 문구, 부정 리뷰 대응 초안(케이스별)

**업무 프로세스**
1. 신규 리뷰 모니터링 (일 1회)
2. 긍정/부정 분류
3. 부정 리뷰 → 대응 초안 즉시 생성 → 승인 후 게시 (SLA: 24시간 내)
4. 긍정 고객 → 후속 리뷰 요청 문구 발송 대상 큐잉
5. 주간 리뷰 요약 리포트 제출

## 5. 랜딩페이지 카피 에이전트

**미션**: 전환 중심 웹·랜딩페이지 문구·구조 초안

**필요 구성**
- 인풋: 서비스/상품 정보, 타겟 고객 페르소나, 경쟁사 랜딩페이지 벤치마크
- 도구: 카피라이팅 프레임워크(PAS/AIDA), 와이어프레임 템플릿
- 아웃풋: 섹션별 카피(헤드라인/서브헤드/베네핏/소셜프루프/CTA), 와이어프레임 구조 초안

**업무 프로세스**
1. 브리프 검토(제품·타겟·경쟁사)
2. 핵심 메시지 3줄 도출
3. 섹션 구조 설계 (히어로 → 베네핏 → 증거 → CTA)
4. 섹션별 카피 초안 작성
5. CRO 에이전트에 전달해 전환요소 리뷰 요청

## 6. 전환최적화(CRO) 에이전트

**미션**: A/B 테스트 문구·레이아웃 제안

**필요 구성**
- 인풋: 현재 페이지 트래픽·전환 데이터, 랜딩페이지 카피 초안
- 도구: 가설-변형-지표 테스트 설계 프레임, 스크롤/클릭 데이터(있는 경우)
- 아웃풋: 테스트 가설 리스트, 변형(A/B) 문구·레이아웃 안, ICE(Impact/Confidence/Ease) 우선순위

**업무 프로세스**
1. 전환 병목 구간 식별 (이탈률 높은 섹션)
2. 가설 수립 (예: "CTA 문구 변경 시 클릭률 개선")
3. 변형안 작성
4. ICE 스코어링으로 우선순위화
5. 승인 후 테스트 실행 요청 → 결과 회수해 반영

## 7. 메타 광고 운영 에이전트

**미션**: 블로그·랜딩페이지를 방문했지만 전환하지 않은 사람을 페이스북·인스타그램 리타겟팅 광고로 재유입시켜 퍼널의 이탈을 회수

**필요 구성**
- 인풋: 메타 픽셀 설치 여부(웹/랜딩페이지에 설치 필요), 리타겟팅 시드 오디언스(방문자·클릭자), 랜딩페이지 카피 초안(광고 소재 재료), 광고 예산 한도
- 도구: 메타 비즈니스 관리자 계정, 메타 마케팅 API 연결, 광고 소재 템플릿(카피+이미지), 건강/민감정보 타겟팅 정책 체크리스트
- 아웃풋: 광고 세트(오디언스·예산·소재 조합) 초안, 소재 A/B 변형, 주간 성과(CPA·ROAS) 요약

**업무 프로세스**
1. 메타 픽셀·전환 이벤트 설치 상태 확인 (없으면 웹 라인에 설치 요청)
2. 리타겟팅 오디언스 정의 (블로그 체류자, 랜딩페이지 방문자, 장바구니/문의폼 이탈자 등)
3. 랜딩페이지 카피를 재료로 광고 소재 2~3개 변형 생성
4. 타겟팅 설정이 민감정보(건강 상태 등) 정책을 위반하지 않는지 체크리스트 대조
5. Human 승인 후 소액 예산으로 캠페인 실행
6. 주간 CPA/ROAS 확인 → 성과 분석 에이전트에 데이터 전달, 저성과 소재는 교체

## 8. 성과 분석 에이전트

**미션**: 채널별 지표 자동 리포트, 개선 우선순위 제안

**필요 구성**
- 인풋: 블로그 트래픽(GA/서치어드바이저), 플레이스 노출·클릭, 랜딩페이지 전환 데이터, 광고 성과(있는 경우)
- 도구: 대시보드 템플릿, 주간 리포트 포맷
- 아웃풋: 주간 성과 리포트(채널별 KPI), 개선 우선순위 Top3

**업무 프로세스**
1. 각 채널 데이터 수집 (주 1회, 매주 월요일)
2. 전주 대비 변화율 계산
3. 이상치·급락 항목 플래그
4. 개선 우선순위 Top3 도출 → 담당 라인 에이전트에 피드백 라우팅
5. 요약 리포트 전달

## 9. 오케스트레이터 에이전트

**미션**: 고객사별 캠페인 캘린더 관리, 산출물 품질 검수 큐잉

**필요 구성**
- 인풋: 전체 고객사 목록, 각 라인 태스크 상태, 콘텐츠 캘린더
- 도구: 태스크 큐/칸반 상태 관리, 품질 체크리스트(포맷·키워드·금지어 자동 검사)
- 아웃풋: 일일 태스크 큐, 1차 스크리닝 통과/반려 결과, 검수용 요약 큐

**업무 프로세스**
1. 매일 아침 각 라인 에이전트에 태스크 배정 (캘린더 기준)
2. 각 에이전트 산출물 수신 시 포맷·필수요소 체크(제목 존재, 키워드 포함, 금지어 없음 등)
3. 통과 → 검수 큐로 전달 / 반려 → 담당 에이전트에 재작업 지시
4. 승인 완료 건 → 발행(수동 게시 또는 예약)으로 전달
5. 일일 진행 현황 요약(오늘 발행 건수, 대기 건수) 리포트

## 10. 클라이언트당 주간 사이클 (요약)

| 요일 | 활동 |
|---|---|
| 월 | 성과 분석 에이전트 주간 리포트 → 오케스트레이터가 이번 주 캘린더 확정 |
| 화~목 | 블로그/웹/플레이스 라인 에이전트가 초안 생산 → 오케스트레이터 1차 스크리닝 |
| 매일 | 리뷰·평판관리 에이전트 모니터링·대응 (SLA 24시간) |
| 금 | 나의 최종 검수·승인 몰아서 처리 → 발행 |
| 상시 | 오케스트레이터가 태스크 상태 관리, 반려 건 재작업 루프 |
