# 고객사 매출이 늘어나는 매커니즘

`docs/revenue-model.md`는 "우리 대행사"의 매출 구조였다. 이 문서는 다른 질문에 답한다: **우리가 하는 마케팅 작업이 고객사(병원·매장)의 실제 매출을 어떤 매커니즘으로 늘리는가.**

## 1. 매출 퍼널(깔때기) 공식

```
고객사 매출 = 노출 × 클릭률(CTR) × 방문자 × 전환율 × 객단가 × 재구매/추천
```

우리가 하는 모든 마케팅 작업은 이 곱셈식의 어느 한 배수를 올리는 개입이다. 배수 하나만 2배가 돼도 최종 매출은 크게 늘어난다(곱셈 구조라서 여러 배수가 같이 조금씩만 올라도 복리로 커진다).

| 단계 | 의미 | 이 배수를 올리는 작업 | 담당 에이전트 |
|---|---|---|---|
| 노출(Reach) | 검색·지도에서 얼마나 자주 뜨는가 | 키워드 커버리지 확대(블로그 발행), 플레이스 등록정보·카테고리 최적화 | 블로그 콘텐츠, 로컬 SEO |
| 클릭(CTR) | 뜬 걸 실제로 클릭하는 비율 | 제목·썸네일 매력도, 플레이스 소개문구·사진 | 블로그 최적화, 로컬 SEO |
| 신뢰·체류 | 방문 후 계속 보고 신뢰하는가 | 콘텐츠 품질, 리뷰 개수·내용 | 블로그 콘텐츠, 리뷰·평판관리 |
| 전환(문의/예약) | 방문자가 실제 행동(전화·예약·문의)하는가 | 랜딩페이지 카피, CTA 배치, A/B 테스트 | 랜딩페이지 카피, CRO |
| 실매출 | 문의가 실제 방문·구매·계약으로 이어지는가 | 문의 품질이 높아지면 간접 기여(마케팅이 직접 통제하는 영역은 아님 — 고객사의 응대력 영역) | — |
| 재구매·추천 | 재방문하거나 남에게 소개하는가 | 사후 리뷰 요청, 꾸준한 신뢰 콘텐츠 | 리뷰·평판관리, 블로그 |

## 2. 숫자로 보면 (병원 파일럿 가정 예시)

| | 운영 전 | 3개월 운영 후 | 무엇이 배수를 올렸나 |
|---|---|---|---|
| 월 검색 노출 | 500 | 2,000 (×4) | 블로그 발행 누적 + 플레이스 최적화 |
| 클릭률 | 3% | 5% | 제목·썸네일, 플레이스 소개문구 최적화 |
| 월 방문자 | 15 | 100 | 노출×클릭률의 결과 |
| 문의 전환율 | 10% | 15% | 랜딩페이지 카피 개선 + 리뷰 신뢰 상승 |
| 월 문의 건수 | 1.5 | 15 | 위 배수들이 곱해진 결과 (약 10배) |

배수 하나하나는 20~70% 정도만 개선돼도, 곱해지면서 문의 건수는 수 배로 뛴다 — 이게 "작은 개선 여러 개가 합쳐진다"는 이 매커니즘의 핵심이다.

## 3. 작업이 시간순으로 배수를 밀어올리는 순서

1. **1~2주차: 로컬 SEO부터** — 플레이스는 반영이 가장 빠르다(등록정보 최적화가 1~2주 내 노출·클릭 배수에 반영). 초기 임팩트를 가장 빨리 보여주는 라인
2. **1주차~ 상시: 블로그 발행 시작** — SEO는 즉시효과가 아니라 누적형. 노출 배수는 몇 주~몇 달에 걸쳐 서서히 오른다
3. **상시: 리뷰·평판관리 가동** — 신뢰 배수는 계속 관리해야 유지되는 배수(한 번 올리고 끝나는 게 아님)
4. **웹/랜딩페이지가 있는 고객: CRO 개입** — 전환 배수를 직접 실험으로 올림
5. **매주: 성과 분석 에이전트가 각 배수(노출/CTR/전환)를 측정** → 가장 낮은(병목인) 배수를 찾아 그 라인에 다음 주 작업을 집중 배정 — 이게 "무엇을 우선 작업할지" 정하는 매커니즘

## 4. 요약

마케팅 작업 = 이 퍼널의 각 배수(노출 → 클릭 → 신뢰 → 전환 → 재구매)를 하나씩 개입해서 올리는 것이고, 8개 에이전트는 각자 정확히 하나 또는 두 배수의 "오너"다. 고객사 매출이 늘어나는 매커니즘은 신비로운 게 아니라 이 곱셈식의 병목을 매주 찾아서 그 라인에 작업을 집중시키는 반복 루프다.
