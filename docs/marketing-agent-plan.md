# AI Stock Platform — 마케팅 에이전트 팀 구축 계획

작성일: 2026-08-24

## 1. 제품 이해 및 전제

현재 리포지토리(`ai-stock-platform`)는 아래 두 스크립트로 구성된 초기 단계 프로젝트입니다.

- `us_market_collector.py`: 미국 주요 지수/종목(QQQ, SPY, SMH, NVDA, TSLA, MSFT, AAPL, AMD) 시세와 Reuters/CNBC 비즈니스 뉴스를 수집해 CSV로 저장
- `convert_news_to_excel.py`: 수집된 뉴스 CSV를 엑셀로 변환

즉 제품의 핵심 자산은 **"미국 시장 데이터 + 뉴스를 매일 자동으로 정리해주는 파이프라인"**이며, 콘솔 출력 문구가 한국어인 것으로 보아 **1차 타겟은 미국 주식에 투자하는 한국어 사용 개인 투자자**로 전제합니다. 아직 사용자 인터페이스, 배포된 서비스, 브랜드 자산은 없는 상태이므로, 마케팅 이전에 "매일 자동 생성되는 콘텐츠 자체가 마케팅 자산이 되는 구조"를 먼저 만드는 것이 핵심 전략입니다.

## 2. 타겟 고객(ICP)과 포지셔닝

- **1차 타겟**: 미국 주식(서학개미)에 투자하는 2030 직장인 개인 투자자
- **핵심 페인포인트**: 미국 장은 밤에 열려 실시간 확인이 어렵고, 영어 뉴스를 매일 요약해서 보기 번거로움
- **포지셔닝**: "출근길 3분, 어젯밤 미국 시장을 가장 빠르고 쉽게" — AI가 매일 밤사이 미국 시장 데이터·뉴스를 요약해 배달하는 개인화 브리핑 서비스

## 3. 결론: 몇 명(개)의 에이전트가 필요한가

**AI 에이전트 6개 + 이를 감독하는 human 운영자 1명**으로 시작하는 것을 권장합니다. 사람을 늘리기보다, 역할이 명확한 전문 에이전트를 나누고 한 명이 오케스트레이션하는 구조가 초기 단계(제품-마켓 핏 검증 전)에 가장 효율적입니다. 팀이 커지면(유료 전환·유료광고 집행 단계) 4번 항목의 "확장 단계" 인력을 추가합니다.

| # | 에이전트 | 핵심 산출물 | 실행 주기 |
|---|---|---|---|
| 1 | 콘텐츠 제작 에이전트 (Content Agent) | 일일 시장 브리핑, 블로그 글, 뉴스레터 초안 | 매일 |
| 2 | 소셜 운영 에이전트 (Social Agent) | X(트위터)/스레드/인스타그램 카드뉴스 초안 | 매일 |
| 3 | SEO·그로스 에이전트 (SEO/Growth Agent) | 키워드 클러스터, 블로그 SEO 최적화, 성장 루프 실험안 | 주간 |
| 4 | 커뮤니티·리텐션 에이전트 (Community Agent) | 뉴스레터 발송, 카카오톡 채널/디스코드 응대, 온보딩 메시지 | 매일~주간 |
| 5 | 퍼포먼스·분석 에이전트 (Analytics Agent) | 채널별 지표 대시보드, A/B 테스트 결과 리포트 | 주간 |
| 6 | 총괄 전략 에이전트 (Strategy/Orchestrator Agent) | 캠페인 캘린더, 우선순위 조정, 각 에이전트 산출물 검수 | 매일 |

- Human 운영자 1명은 (1) 브랜드 톤 최종 승인, (2) 사실 검증(투자 관련 콘텐츠는 오탈자/과장 표현 리스크가 커 반드시 사람 검수 필요), (3) 유료 채널 예산 집행을 담당합니다.
- 유료 마케팅(퍼포먼스 광고)을 본격 집행하는 단계부터는 **퍼포먼스 마케터 1명(human)**을 추가해 광고 소재 검수·매체 운영을 맡기는 것을 권장합니다.

## 4. 단계별 실행 로드맵

### Phase 1 — 콘텐츠 엔진 구축 (1~2주)
- 브랜드 톤/보이스 가이드, 핵심 메시지 3줄 요약 확정
- `us_market_collector.py` 출력물을 입력으로 받아 "일일 브리핑 텍스트"를 자동 생성하는 콘텐츠 에이전트 로직 구현 (본 PR의 `marketing_content_agent.py` 참고)
- 콘텐츠 품질 기준(오탈자, 투자 유의 문구 포함 여부) 체크리스트 수립

### Phase 2 — 채널 런칭 (3~6주)
- 뉴스레터(예: 스티비/메일침프) + X/스레드 채널 개설 및 매일 자동 브리핑 발행
- SEO 블로그(예: 벨로그/미디엄/자체 블로그) 주 3회 발행, 핵심 키워드("서학개미", "미국주식 브리핑" 등) 타겟팅
- 초기 커뮤니티(오픈채팅/디스코드) 개설, 얼리유저 30~50명 확보

### Phase 3 — 성장 루프 검증 (7~10주)
- 추천/공유 유도 장치(브리핑 카드 공유, 친구 초대 시 프리미엄 기능 제공 등) 테스트
- 콘텐츠별 CTR·구독전환율 분석 → 상위 20% 포맷으로 자원 집중
- 유료 채널(메타/구글 소규모 예산) A/B 테스트 시작

### Phase 4 — 확장 (11주~)
- 성과가 검증된 채널에 예산 증액, 퍼포먼스 마케터(human) 채용
- 유료 구독/프리미엄 브리핑 모델 연계한 리텐션 캠페인 강화

## 5. 핵심 KPI

- 콘텐츠: 뉴스레터 구독자 수, 오픈율(목표 40%+), 블로그 유입 세션
- 소셜: 팔로워 성장률, 게시물당 참여율
- 그로스: 신규 가입 대비 활성 사용자(리텐션 W1/W4)
- 전환: 무료→유료(프리미엄) 전환율 (구독 모델 도입 시)

## 6. 리스크 및 대응

- **투자 자문 오인 리스크**: 모든 콘텐츠 하단에 "투자 참고용, 투자 판단 및 책임은 본인에게 있음" 문구 자동 삽입 (콘텐츠 에이전트 템플릿에 기본 포함)
- **데이터 정확성 리스크**: `us_market_collector.py`의 `status: error` 종목은 자동으로 콘텐츠에서 제외하고 사람이 재확인 후 발행
- **콘텐츠 단조로움**: 주간 단위로 포맷 로테이션(브리핑/딥다이브/Q&A)을 전략 에이전트가 관리
