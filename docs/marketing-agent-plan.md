# 한국 마케팅 시장 정복 플랜 — 올인원 AI 마케팅 에이전트

작성일: 2026-08-24 (v2, 기존 v1 계획 폐기 후 재작성)

## 0. 방향 전환

v1 계획은 `ai-stock-platform` 하나만을 위한 브리핑 콘텐츠 마케팅이었다. 목표를 다시 정의한다:

> **하나의 서비스를 홍보하는 마케터가 아니라, "블로그 + 웹 + 플레이스(로컬 검색)"를 무기로 어떤 고객사든 마케팅을 대행·집행할 수 있는 올인원 AI 마케팅 에이전트 조직을 만들어 한국 마케팅 시장을 장악한다.**

핵심 산출물 3종은 고정한다.
1. **블로그를 업계 최고 수준으로** — SEO 콘텐츠 생산·최적화
2. **웹(홈페이지/랜딩페이지)을 최고로** — 전환 잘 되는 웹 제작·개선
3. **"특정한 곳"을 고객이 먼저 찾게 만드는 마케팅** — 플레이스/로컬 검색(네이버 플레이스·지도·리뷰) 최적화, 즉 병원·매장·지역 비즈니스가 검색에서 상위 노출되게 만드는 것

## 1. 사업 포지셔닝

- **형태**: AI 에이전트가 콘텐츠 생산·최적화를 상시 자동화하고, 사람은 전략/영업/규제 검수만 담당하는 경량 마케팅 대행사
- **시작 버티컬**: 병원·의료(수요 확실, 단가 높음, 광고 규제로 진입장벽 높아 선점 시 방어력 강함) → 이후 뷰티, F&B, 법률·세무 등 지역 기반 업종으로 확장
- **차별점**: 사람 대행사 대비 3~5배 빠른 콘텐츠 산출 속도 + 매주 자동 성과 리포트로 이탈 방지 + 업종별 규제 준수 템플릿 선점

## 2. 팀 구성: 몇 명(개)이 필요한가

**AI 에이전트 8개(3개 서비스 라인 + 오케스트레이터) + Human 1명(나 혼자)**으로 시작한다.

### 서비스 라인별 AI 에이전트

| 라인 | 에이전트 | 역할 |
|---|---|---|
| 블로그 | 블로그 콘텐츠 에이전트 | 키워드 기반 SEO 블로그 포스트 초안 생성 |
| 블로그 | 블로그 최적화 에이전트 | 제목·썸네일·내부링크·발행 주기 최적화 |
| 웹 | 랜딩페이지 카피 에이전트 | 전환 중심 웹/랜딩페이지 문구·구조 초안 |
| 웹 | 전환최적화(CRO) 에이전트 | A/B 테스트 문구·레이아웃 제안 |
| 플레이스 | 로컬 SEO 에이전트 | 네이버 플레이스·지도 노출 체크리스트, 등록정보 최적화 |
| 플레이스 | 리뷰·평판관리 에이전트 | 리뷰 유도 문구, 부정 리뷰 대응 초안 |
| 공통 | 성과 분석 에이전트 | 채널별 지표 자동 리포트, 개선 우선순위 제안 |
| 공통 | 오케스트레이터 에이전트 | 고객사별 캠페인 캘린더 관리, 산출물 품질 검수 큐잉 |

### Human 1명 (나) — 1인 3역

AM/QA/총괄 검수를 별도로 채용하지 않고, 8개 에이전트가 만든 산출물의 최종 승인·영업·규제 검수를 전부 혼자 수행한다.

| 역할(모자 3개) | 담당 |
|---|---|
| 총괄 검수 | 브랜드 톤 최종 승인, 업종별 광고법(의료법 등) 규제 검수 |
| 영업/고객성공 | 신규 고객 영업, 온보딩, 고객 커뮤니케이션 |
| 콘텐츠 QA | AI 산출물 팩트체크·오탈자 검수 (특히 의료·법률 등 규제 업종) |

확장 기준(rule of thumb): 혼자서 병목 없이 감당 가능한 동시 고객사는 **3~5곳** 수준. 오케스트레이터 에이전트가 산출물을 큐잉·1차 스크리닝해 내가 검수할 양을 줄여주는 것이 핵심이며, 이 한도를 넘으면(고객사 6곳+) 그때 처음으로 사람(AM 또는 QA) 채용을 검토한다 — 그 전까지는 AI 에이전트 8개만으로 확장한다.

## 3. 실행 로드맵

- **Phase 0 (1~4주) 파일럿**: 지인/저가 파일럿 고객 3곳(병원 1, 매장 1, 기타 1) 무료 또는 저가로 진행 → 사례(레퍼런스) 확보, 에이전트 산출물 품질 기준 확립
- **Phase 1 (5~10주) 첫 유료 고객**: 파일럿 사례로 세일즈 자료 제작, 유료 고객 5곳 확보. 블로그+플레이스부터 먼저 판매(웹 제작보다 착수 빠름)
- **Phase 2 (11~20주) 버티컬 템플릿화**: 병원 등 업종별 콘텐츠·규제 체크리스트 라이브러리화, 고객 5곳까지 혼자 운영해보며 병목 지점 파악 → 6곳 이상이면 그때 처음 채용 검토
- **Phase 3 (21주~) 시장 장악**: 사례 기반 인바운드 영업 전환, 업종 확장(뷰티/F&B/법률), 지역 확장

## 4. 핵심 KPI

- 고객사 신규 계약 수 / 이탈률(Churn)
- 고객사별: 블로그 발행 후 유입 세션, 플레이스 노출·클릭수, 웹 전환율
- 내부: 에이전트 산출물 1차 승인율(사람 QA 통과율) — 낮으면 템플릿 개선 신호

## 5. 리스크 및 대응

- **업종별 광고 규제 위반 리스크** (의료법 등): 업종별 규제 체크리스트를 콘텐츠 에이전트 프롬프트에 하드코딩, Human QA 필수 게이트로 설정
- **네이버 알고리즘 의존 리스크**: 블로그·플레이스·웹(자체 도메인 SEO)로 채널 분산해 특정 플랫폼 리스크 완화
- **AI 콘텐츠 품질 편차**: 고객사 계약 전 반드시 파일럿 산출물 샘플 승인 절차를 거침

## 6. 상세 스펙

각 에이전트의 필요 구성(인풋·도구·아웃풋)과 단계별 업무 프로세스는 [`docs/agent-specs.md`](./agent-specs.md) 참고.
