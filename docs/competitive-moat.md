# 우리만의 노하우 — 경쟁 대행사가 못 따라오는 것

## 0. 왜 지금까지 내용만으론 부족한가

블로그 SEO, 플레이스 최적화, 랜딩페이지 CRO — 이건 한국의 수천 개 대행사가 이미 팔고 있는 상품이다. "AI로 자동화했다"는 것도 이제는 차별점이 아니다(다들 그렇게 말한다). 이것만으로는 "우리도 남들만큼 함" 수준이지, 시장을 장악할 근거는 안 된다.

진짜 해자는 아래 네 가지에서 나온다. 공통점은 전부 **시간이 지날수록 격차가 벌어지는 축적형 자산**이라는 것 — 경쟁사가 오늘 우리를 카피해도 격차를 못 좁힌다.

## 1. 데이터 플라이휠 (Proprietary Performance Data)

일반 대행사는 담당자 개인의 감·경험에 의존한다. 우리는 모든 고객사의 `(키워드 × 콘텐츠 구조 × 전환율)` 데이터가 하나의 시스템에 쌓인다.

- 병원 버티컬에서 "무릎 통증" 계열 키워드는 어떤 제목 패턴이 CTR이 높은지, 어떤 CTA 문구가 전환율이 높은지가 고객사 수가 늘수록 정교해진다
- 대행사 한 곳이 개별 고객을 담당하는 방식으로는 절대 이 규모의 데이터를 못 쌓는다 — 신규 진입자는 시간을 들여도 이 격차를 못 따라잡는다(우리가 먼저 시작했으므로)
- **실행**: 성과 분석 에이전트가 모든 고객사 데이터를 업종별 패턴 라이브러리로 축적하고, 블로그/랜딩페이지 콘텐츠 에이전트가 신규 산출물 생성 시 이 라이브러리를 자동 참조하게 만든다

## 2. 초고속 실험 루프 (Compound Iteration Speed)

사람 대행사는 콘텐츠 1건 만드는 데 담당자가 며칠 걸리고, 사실상 실험할 리소스가 없다. 우리는 같은 키워드에 대해 제목·CTA 여러 변형을 동시에 만들고, 성과 분석 에이전트가 주기적으로 승자를 자동 선별해 다음 라운드에 반영한다.

- "일주일에 1번 실험"이 아니라 "매 콘텐츠가 실험"인 구조 → 최적화 곡선이 경쟁사보다 훨씬 빨리 수렴한다
- 같은 예산으로 시간이 지날수록 경쟁사 대비 전환율 격차가 벌어진다 — 이건 나중에 경쟁사가 따라오려 해도 방어 가능한 격차다

## 3. 업종 플레이북 자산화 (Vertical Playbook Moat)

신규 대행사가 병원 마케팅에 뛰어들면 처음부터 배워야 한다(의료광고법, 어떤 표현이 먹히는지, 뭐가 금지인지). 우리는 이걸 재사용 가능한 자산으로 코드화한다.

- 업종별(정형외과/피부과/치과 등) 금지어·톤·전환 잘 되는 콘텐츠 구조를 템플릿화 → 신규 고객 온보딩 즉시 첫 산출물부터 높은 품질
- 이 라이브러리가 커질수록 다음 신규 업종 진입 속도도 빨라진다 — 선점 업종이 늘수록 다음 업종 진입이 더 쉬워지는 복리 구조
- 규제 산업(의료 등)은 이 플레이북 자체가 진입장벽이라, 먼저 만든 사람이 오래 우위를 가져간다

## 4. 성과 연동 가격 (Risk-Shifted Pricing)

한국 대행사 대부분은 정액 월정액이다. 고객 입장에서 "돈 냈는데 효과 없으면?"이 계약을 막는 가장 큰 장벽이다. 우리는 AI 운영으로 원가가 낮아서 성과 연동 요금제(기본료+문의 건당 보너스, 또는 초기 무료+성과 나오면 정식 계약 전환)를 실제로 감당할 수 있다.

- 사람 대행사는 인건비 고정비 구조 때문에 이 리스크를 못 진다 — 구조적으로 못 따라하는 차별점
- 고객 입장에서 계약 리스크가 낮아지므로 계약 전환율 자체가 오른다 — `docs/revenue-model.md`의 "루프 1(신규 획득)" 속도를 근본적으로 높이는 무기

## 5. 이 4개가 왜 "노하우"인가

전부 복제 불가능한 축적형 자산이다. 경쟁사가 우리 블로그 스타일이나 체크리스트는 베낄 수 있어도, 우리가 쌓은 성과 데이터·실험 히스토리·업종 플레이북·낮은 원가 구조는 시간을 들이지 않고는 못 베낀다. 이게 "한국 마케팅 시장을 장악한다"는 목표의 실질적 근거다.

## 6. Phase 로드맵에 반영

- Phase 0~1: 1번(데이터 플라이휠)·2번(실험 루프)의 데이터 수집 구조를 처음부터 설계해둔다 — 나중에 추가하면 과거 데이터가 없어 늦다
- Phase 1~2: 3번(업종 플레이북)을 병원 버티컬부터 문서화·템플릿화 시작
- Phase 1: 4번(성과 연동 가격)을 신규 고객 1~2곳에 시범 적용해 검증
