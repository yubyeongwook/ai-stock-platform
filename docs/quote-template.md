# 견적서 템플릿

`docs/service-agreement-template.md`(계약서)와 짝을 이루는 문서. 유료 전환 시 계약서 서명 전에 먼저 보내는 간단한 견적서다.

---

**견적서**

발행일: ____________
수신: ____________(고객사명)
발신: 매출엔진

## 제안 서비스

| 항목 | 내용 | 월 비용 |
|---|---|---|
| 블로그 | 월 __건 SEO 블로그 콘텐츠 제작 | |
| 플레이스 | 네이버 플레이스 최적화·관리 | |
| 리뷰·리텐션 | 리뷰 요청·재방문 유도 메시지 | |
| (선택) 메타 광고 운영 | 광고비의 __% 또는 정액 __원 | |

**월 합계**: ____________원 (부가세 별도)

## 적용 조건

- 계약 기간: __개월 (자동 갱신 여부: )
- 산출물 검수: 발행 전 고객사 승인 필수
- (노무법인 등 자격사 고객) 본 견적은 콘텐츠·광고 집행 대행에 대한 대가이며, 사건 수임·문의 성사와 연동되지 않음

## 참고

- 사업자등록 완료 전까지는 무료로 진행 — 이 견적은 사업자등록 완료 후 정식 계약 전환 시점에 사용
- 정식 계약 시 [`docs/service-agreement-template.md`](./service-agreement-template.md) 사용, 변호사 검토 필수
- 가격 산정 근거는 [`docs/revenue-model.md`](./revenue-model.md) 참고 — 실제 파일럿 결과로 조정 가능
