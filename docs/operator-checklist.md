# 내가 할 일 & 필요한 것 (Phase 0 실행 체크리스트)

9개 AI 에이전트가 대신할 수 없는, **오직 사람(나)만 할 수 있는 일**과 **지금 당장 있어야 실행 가능한 것**을 정리한다. `docs/marketing-agent-plan.md`의 Phase 0(1~4주)를 실제로 시작하기 위한 체크리스트다.

## 1. 지금 당장 해야 할 일 (사람만 할 수 있는 것)

- [x] **파일럿 고객 2곳 섭외** — 확보됨: 음식점(직접 관리), 노무사무실(소속). 콜드아웃리치 없이 시작 가능. 치과도 접근권한은 있지만 Compliance 게이트 준비 전까지 의도적으로 보류(Phase 3)
- [x] **내 대행 브랜드 정하기** — **매출엔진** / "블로그 개수가 아니라 매출로 증명하는 마케팅"
- [x] **가격 정책 결정** — **사업자등록 완료 전까지는 무료로 진행**(4주 한정이 아니라 등록 시점까지 — 등록 안 된 상태로 돈 받으면 세금계산서 발행이 애매해지기 때문). 조건: 사례(포트폴리오·후기) 사용 동의. 사업자등록 완료 후 Phase 1 정가로 전환: **블로그+플레이스 패키지 90만원/월부터**(`docs/revenue-model.md` 앵커의 하한선). 노무법인도 동일 패키지이나 정액만, 문의·수임 연동 과금 금지(확정 원칙)
- [x] **계약서 템플릿 준비** — [`docs/service-agreement-template.md`](./service-agreement-template.md), 노무법인 등 자격사 고객용 특약(제9조: 정액/광고비 비례만, 수임·문의 연동 금지) 포함. **실제 사용 전 변호사 검토 필수** — 견적서는 아직 없음
- [x] **사업자 등록 여부 결정** — **사업자등록(간이과세자로 시작) 추천**. 노무법인 등 법인 고객이 세금계산서를 요구할 가능성이 높고, 간이과세자는 초기 매출 구간에서 부가세 부담이 낮음. **주의**: 간이과세자 기준금액·요건은 세법 개정으로 바뀔 수 있어 정확한 현재 기준은 검증하지 않았다 — 등록 전 세무사 확인 필수
- [x] **온보딩 브리프 양식 만들기** — [`docs/onboarding-brief-form.md`](./onboarding-brief-form.md), 답변을 `clients/*.json` 필드로 바로 옮길 수 있게 매핑까지 포함
- [x] **업종별 규제 최소 학습** — 노무사무실 파일럿: 공인노무사법 제27조의2 확인 완료(1항 사건수임 대가성 소개·알선 금지, 2항 이익분배 금지) — 마케팅 계약 범위를 "콘텐츠·광고 대행"으로만 한정하고 과금은 정액/광고비 비례만 사용(`docs/competitive-moat.md` 4절). 음식점: 식품위생법상 표시·광고 기본 규정만 확인해도 충분

### 치과 파일럿 전용 가드레일 (지금은 안 씀 — Phase 3에 치과 착수할 때 참고)

의료법상 의료광고 규제 취지를 반영한 최소 체크리스트다. **정확한 조문·적용 범위는 검증하지 않았다 — 실제 콘텐츠 발행 전 반드시 별도로 확인할 것.**

- [ ] 아래 표현 유형은 사용하지 않는다: 치료효과 보장·단정("100% 완치", "무통증" 등), 다른 병원과의 비교·우열 표현, 환자 치료경험담(후기)의 광고 활용, 거짓·과장 표현
- [ ] 옥외광고 등 특정 매체는 사전 심의 대상일 수 있다 — 블로그·SNS 자체 콘텐츠는 통상 사전심의 대상이 아니라고 알려져 있으나 정확한 적용 범위는 확인 필요
- [ ] 위 금지 표현을 치과 고객사의 `clients/*.json`에 `banned_terms`로 등록한다 — `integrations/llm_writer.py`가 이미 이 필드를 읽어 프롬프트에 자동 반영하도록 만들어져 있다(레벨 3 게이트: 최종 발행 전 반드시 사람이 재검수)

## 2. 필요한 계정·도구

### 필수 (파일럿 시작 전 있어야 함)

| 항목 | 용도 | 비고 |
|---|---|---|
| 블로그 플랫폼 계정 | 블로그 라인 발행처 | 네이버 블로그(사업자/브랜드 계정) 또는 티스토리 |
| 네이버 서치어드바이저 | 블로그 성과 데이터 | 사이트 소유 확인 필요, 성과분석 에이전트의 인풋 소스 |
| 네이버 스마트플레이스 | 플레이스 라인 등록·관리 | 고객사(업체)별로 별도 계정/권한 필요 |
| 문서·태스크 관리 도구 | 오케스트레이터 역할을 지금은 내가 수동 대체 | Notion, 구글시트 등 무엇이든 — 캘린더+칸반 형태면 충분 |
| LLM API 키(`ANTHROPIC_API_KEY`) | 블로그 본문을 실제로 자동 생성 | 연동 코드(`integrations/llm_writer.py`)는 이미 완성·검증됨 — 키만 `.env`에 넣으면 바로 동작 |
| 카카오톡 채널(고객사 계정) + 알림톡 템플릿 사전승인 | 리뷰 요청·예약 리마인더·재방문 유도 발송 | 템플릿 심사에 며칠 걸릴 수 있어 파일럿 시작 전에 미리 신청해둬야 함 |

### Phase 1부터 (유료 고객 생기면)

| 항목 | 용도 |
|---|---|
| Google Analytics(GA4) | 고객 웹사이트 있는 경우 전환 데이터 |
| 디자인 툴(Canva 등) | 블로그 썸네일, 플레이스 사진 편집 |

| 메타 비즈니스 관리자 계정 | 리타겟팅 광고 운영 — 파일럿에서 전환이 검증된 고객부터 연결, Phase 0에는 필요 없음 |

## 4. 우선순위 (지금 이 순서대로)

**1절(사람만 할 수 있는 준비)은 치과 가드레일(Phase 3용) 빼고 전부 완료됨.** 남은 건 아래 4가지뿐이고, 전부 나(사람)의 실제 행동이 필요해 코드로 대신할 수 없는 것들이다.

1. **2곳(음식점·노무사무실)에 [`docs/onboarding-brief-form.md`](./onboarding-brief-form.md) 보내서 브리프 수집**
2. **`ANTHROPIC_API_KEY` 발급 + `.env` 등록** — 코드는 이미 완성, 키만 넣으면 블로그 본문 생성 실사용 가능
3. **블로그 플랫폼 + 서치어드바이저 + 스마트플레이스 계정 개설** (2곳 각각)
4. 브리프 도착하면 `clients/*.json`으로 옮겨서 `orchestrator.py` 돌리고 산출물 품질 확인

계약서·견적서는 파일럿이 유료 전환될 때(Phase 1) 실제 금액 채워서 변호사 검토 후 사용.
