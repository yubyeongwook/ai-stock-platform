# 상품 기획 — 애드센스 승인 준비 점검 (내부 전용, 비공개)

**주의: 이 문서는 내부 참고용이다. 고객에게 보여주거나 웹사이트에 공개하지 않는다.**
나중에 마케팅 웹사이트를 만들 때 이 문서를 기준으로 상품 페이지를 만든다 — 지금은 가격·구성만 내부적으로 확정해두는 단계다.

구현체: `adsense_readiness_agent.py` / `adsense_essential_pages.py` (이 저장소).
근거 문서: [`docs/revenue-model.md`](./revenue-model.md)(가격 구조 컨벤션), [`docs/quote-template.md`](./quote-template.md)(견적서 포맷).

## 1. 상품명 (가안)

**"애드센스 승인 준비 점검"** (영문 표기 필요 시: AdSense Readiness Check)

절대 "애드센스 승인 대행" / "승인 보장"으로 부르지 않는다 — 검색순위 1위 보장을 안 파는 것과 같은 이유. 구글이 사람+시스템으로 직접 심사하는 것이라 외부에서 승인 자체를 대신 해줄 방법이 없다. 이 상품이 파는 것은 **"통과 확률을 높이는 준비 상태 점검·수정"**이지 승인 그 자체가 아니다.

## 2. 구성 (1회성, 올인원)

| 단계 | 내용 |
|---|---|
| 1차 진단 | 도메인 실사 5개 항목(HTTPS, ads.txt, robots.txt, sitemap, 필수페이지) 자동 진단 + 리포트 |
| 자동 수정 | 기술적으로 고칠 수 있는 항목(ads.txt 재생성, robots.txt 크롤러 허용 규칙, 소개/개인정보처리방침/연락처 페이지 초안) 자동 생성 |
| 게시 지원 | 생성된 페이지·파일을 실제 사이트에 반영 (플랫폼 API로 되는 부분은 자동, 안 되는 부분—예: Blogger 테마 편집기—은 사람이 게시하도록 안내) |
| 2차 진단 | 수정 반영 후 재진단 1회 포함 — 실제로 고쳐졌는지 확인 |
| 수동 점검 체크리스트 | 자동화 불가 항목(콘텐츠 양·질, 정책 위반 여부, 운영 기간, 모바일 최적화)에 대한 구체적 자가점검 가이드 제공 |

## 3. AI가 할 일 vs 사람이 할 일

### AI가 (거의 무료 한계비용으로) 자동 처리
- [ ] HTTPS 접속 상태 진단
- [ ] ads.txt 존재·형식·인증기관ID(`f08c47fec0942fa0`) 정확성 진단 + 정상 ads.txt 자동 생성
- [ ] robots.txt의 Googlebot·Mediapartners-Google 차단 여부 진단 + 정상 규칙 자동 생성
- [ ] sitemap.xml URL 개수 카운트
- [ ] 필수 페이지(소개/개인정보처리방침/연락처) 존재 여부 홈페이지 스캔
- [ ] 소개/개인정보처리방침/연락처 페이지 초안 자동 생성 (검증된 사실만 사용, 지어내지 않음)
- [ ] 수정 후 재진단 실행 및 결과 리포트

### 사람이 반드시 해야 하는 일 (AI가 판단·대행 불가)
- [ ] **콘텐츠 실사**: 독창적인 글 15~25편 이상, 편당 800~1,000자 이상인지 직접 확인 — "검색엔진용" 티가 나는 얕은 글 걸러내기
- [ ] **정책 위반 여부 검토**: 성인·폭력·저작권 침해 콘텐츠 없는지
- [ ] **사이트 운영 기간 확보**: 최소 1개월, 이상적으로 3~6개월 — 이건 그냥 시간이 지나야 함, 단축 불가
- [ ] **모바일 레이아웃 실제 확인**: 실기기/에뮬레이터로 깨짐 없는지 눈으로 확인
- [ ] **자동 생성 페이지 최종 검수 후 게시**: AI 초안을 그대로 쓸지 다듬을지 결정, 플랫폼 UI에서 직접 게시 (API 미지원 플랫폼의 경우)
- [ ] **구글 애드센스 실제 신청서 제출**
- [ ] **심사 결과 대기 및 확인** (수 일~수 주, AI가 앞당길 수 없음)

## 4. 가격

**이 상품은 기존 월정액 고객 대상 부가서비스가 아니라, 일반 대중을 대상으로 하는 독립 마케팅 상품이다** — 진단(diagnosis) + 자동화(자동 수정)를 묶어서 신규 고객에게 직접 판매한다. 별도 계약 관계가 없는 사람이 이 상품 하나만 사는 구조.

가격 근거: (1) 자체 작업량 추정 + (2) 실제 경쟁사 시장조사(웹서치, 2026-08-26). 경쟁사(크몽·숨고 "애드센스 승인 대행")는 스니펫 기준 **최소 20만원 이상**이 흔했고, 대부분 "끝까지 승인/미승인 시 환불" 같은 **승인 자체를 보장하는 모델**로 판매 중이었다 (원문 페이지는 이 세션 네트워크 정책상 직접 열람 불가 — 검색 스니펫 기반, 완전 검증된 숫자는 아님).

| 항목 | 금액 |
|---|---|
| **애드센스 승인 준비 점검 (진단+자동화 올인원, 1회성)** | **220,000원** (부가세 별도) |

포함 내역: 1차 진단(5개 기술 항목) + 자동 수정(ads.txt/robots.txt 재생성, 소개·개인정보처리방침·연락처 페이지 초안 자동 생성) + 2차 진단(재확인 1회) + 수동 점검 가이드 문서.

**포지셔닝**: 경쟁사 최저가(20만원대) 근처로 잡되, **승인 보장/환불 조건은 걸지 않는다** — 대신 "실제로 뭘 고쳤는지"(재생성된 ads.txt·robots.txt·페이지 초안, 진단 전/후 리포트)를 눈에 보이는 산출물로 제시해서 차별화한다. 승인 보장형 경쟁사보다 저렴하면서 정직하게 파는 포지션.

(참고: 기존 월정액 고객에게 무료로 끼워 파는 번들 방식은 다른 옵션이었으나, 이번 요청은 그것과 무관한 별도 마케팅 상품 건이라 위 가격만 확정한다.)

## 5. 확장 패키지 — 웹사이트 제작 + 월 고정관리비

"애드센스 준비 점검"만 사는 게 아니라, **웹사이트를 아예 새로 만들어주고 + 월 고정관리비를 받는** 더 큰 패키지로 파는 경우의 가격.

**주의**: 이 패키지의 웹 제작·관리비 숫자는 애드센스 경쟁사 시장조사(위 4절)와 달리 **실제 시장조사를 거치지 않은 자체 추정치**다 — `revenue-model.md`의 기존 "웹/랜딩페이지 제작 200~500만원" 대역을 참고해 심플한 콘텐츠형 사이트 기준으로 하한선 근처를 잡았다.

| 항목 | 금액 | 비고 |
|---|---|---|
| 웹사이트 제작 (1회성) | **1,500,000원** | 애드센스 운영을 목적으로 한 심플한 콘텐츠/블로그형 사이트 기준. 복잡한 기능(회원가입, 결제, 예약 등) 있는 사이트는 `revenue-model.md` 기존 대역(200~500만원)으로 별도 산정 |
| 애드센스 승인 준비 점검 | **무료 포함** | 웹을 새로 만들면서 필수 페이지·ads.txt·robots.txt를 처음부터 표준대로 넣으면 되므로, 이 상품(4절, 22만원)을 별도로 또 받을 이유가 없음 — 웹 제작가에 흡수 |
| 월 고정관리비 | **150,000원/월** | 호스팅·도메인 관리, 월 1회 5개 기술 항목 자동 재진단, 애드센스 정책 위반 여부 모니터링, 경미한 오류 수정(월 1~2건). **콘텐츠 제작(글쓰기)은 불포함** — 필요하면 `revenue-model.md`의 블로그 상품(월 50~80만원)을 별도 계약해야 함 |

**총액 예시**: 최초 1,500,000원(1회성) + 이후 매월 150,000원

**포지셔닝 근거**: 월 고정관리비는 순수 기술 유지보수 성격(콘텐츠 생산 없음)이라 `revenue-model.md`의 최저가 반복 상품(플레이스 단독 30~50만원/월)보다 훨씬 낮게 잡았다 — 이걸 미끼로 나중에 블로그/플레이스 패키지로 업셀하는 루프 2의 진입점으로 쓸 수 있다. 다만 이 숫자는 시장조사 없이 잡은 것이므로 실제 판매 전 반드시 재검토할 것.

## 6. 판매 시 반드시 지킬 문구 규칙

- "승인 보장" / "100% 통과" / "무조건 승인" — 절대 사용 금지
- 대신 사용할 표현: "승인 확률을 높이는 준비 점검", "기술적 결격 사유 사전 제거", "구글 공식 가이드라인 기준 점검"
- 견적서·계약서 작성 시 `docs/quote-template.md`, `docs/service-agreement-template.md` 포맷에 맞추고, 위 문구 규칙을 명시적으로 반영
